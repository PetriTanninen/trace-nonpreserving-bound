# Publication and attribution

The manuscript in `paper/` is the author-approved final version. The software is attributed to Petri Tanninen, Sentient Machine Corporation, and licensed under the standard MIT License. The PDF includes the author's dual affiliation and public contact information.

The package includes a GitHub Actions workflow with read-only repository permissions to run tests remotely. The local test results are retained in `results/reference/`.

**Identifiers and Archival**
The repository and manuscript are cross-linked using permanent Zenodo DOIs:
* The code package contains the paper's DOI in `CITATION.cff` and `README.md`.
* The manuscript contains the code's DOI in the "Data and Code Availability" section.

The computations illustrate the proof and check explicit examples; they are not used as a substitute for the analytic argument. The manuscript's license is chosen separately by the author at the time of arXiv submission.
